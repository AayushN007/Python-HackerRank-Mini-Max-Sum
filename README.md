# Python HackerRank - Mini-Max Sum

## 📘 Overview

This repository contains a Python solution for the **Mini-Max Sum** problem from HackerRank.

The program takes an array containing five integers and calculates:

- The minimum sum possible by adding exactly four elements.
- The maximum sum possible by adding exactly four elements.

---

## 📌 Problem

Given five positive integers, find the minimum and maximum values that can be calculated by summing exactly four of the five integers.

The results are printed on the same line.

---

## 💡 Approach

The array is first sorted in ascending order.

After sorting:

```text
Smallest 4 elements → Minimum Sum
Largest 4 elements  → Maximum Sum
